Proyek Membangun Shell Scripting untuk Monitoring Server

📌 Ringkasan Proyek

Proyek ini merupakan submission untuk kelas Belajar Administrasi Sistem Linux di Dicoding. Dalam proyek ini, saya membangun Shell Script yang berfungsi untuk memantau penggunaan memori dan ruang penyimpanan disk secara otomatis di sistem Linux. Script ini dibuat untuk membantu seorang Linux System Administrator dalam mengelola server dengan lebih efisien.

✅ Kriteria yang Dipenuhi

Membuat Shell Script (script.sh) untuk monitoring server.

Menampilkan ukuran memori dalam satuan megabytes.

Menampilkan penggunaan ruang disk dalam satuan gigabytes.

Menampilkan filesystem dan persentase penggunaan disk (tanpa menyertakan tmpfs).

Memastikan output ditampilkan dengan format yang rapi dan mudah dibaca.

Menambahkan jeda 1 detik di antara setiap output perintah.

Menyimpan command history ke dalam berkas history.txt.
