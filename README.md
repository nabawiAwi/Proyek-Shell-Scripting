# Proyek Membangun Shell Scripting

## 📌 Ringkasan Proyek
Dalam proyek ini, saya membangun **Shell Script** untuk mengotomatiskan pemantauan penggunaan memori dan disk pada sistem Linux, sesuai dengan skenario yang diberikan.

## ✅ Kriteria yang Dipenuhi
- Membuat **shell script** (`script.sh`) untuk:
  - Menampilkan ukuran memori dalam MB.
  - Menampilkan penggunaan ruang disk dalam GB.
  - Menampilkan penggunaan disk tanpa menyertakan `tmpfs`.
- Output harus ditampilkan dengan format yang rapi dan mudah dibaca.
- Menambahkan jeda **1 detik** antara setiap output.
- Melampirkan **command history** (`history.txt`).
